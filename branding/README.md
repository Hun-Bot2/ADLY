# ALDY branding

| File | Use |
|---|---|
| `aldy-icon.svg` | App icon source (1024 grid, rounded square, Tableau blue, Tableau-yellow check). |
| `aldy-icon-{1024,512,256,128}.png` | Icon exports for docs, store pages and social previews. |
| `aldy-mark.svg` | The icon cropped to its rounded square; the sidebar logo inlined in `desktop/ui/index.html` and `hosted/public/index.html`. |
| `banner.svg` / `banner.png` | README banner. Generated by `make_banner.py`; edit the script, not the SVG. |

Regenerate:

```sh
python3 branding/make_banner.py && rsvg-convert -w 1600 branding/banner.svg -o branding/banner.png
for s in 1024 512 256 128; do rsvg-convert -w $s -h $s branding/aldy-icon.svg -o branding/aldy-icon-$s.png; done
```

App bundle icons (`desktop/src-tauri/icons/`) are generated from `aldy-icon.svg` with `tauri icon` (see AGENTS.md).
The banner's activity grid is a fixed seeded pattern, not learner data. Colours: `#4e79a7` primary, `#edc948` check,
grid `#e5e8eb → #3d6188`.
